# Design and Implementation of Parallel Matrix Multiplication Using OpenMP

## 📌 Project Overview

This project demonstrates the implementation of **parallel matrix multiplication using OpenMP** to improve computational performance by distributing matrix operations across multiple threads.

It compares the execution time of sequential and parallel matrix multiplication and displays the performance results through a web-based graphical user interface.

The application allows users to:
- Select the matrix size.
- Choose the number of threads.
- Perform matrix multiplication.
- View the resulting matrix.
- Compare sequential and parallel execution times.
- Analyze speedup and parallel efficiency through performance charts.

## 🎯 Objectives

- To understand parallel programming using OpenMP.
- To implement sequential and parallel matrix multiplication.
- To compare execution time and performance.
- To understand the impact of multiple threads on computation.
- To visualize performance using a web interface.

## 🏗️ Project Architecture

The application follows this workflow:

1. The user selects the matrix size and number of threads through the web interface.
2. The frontend sends the matrix data to the Flask backend.
3. Flask passes the input to the compiled C program.
4. The C program performs sequential matrix multiplication.
5. OpenMP distributes the parallel computation across multiple threads.
6. Execution times are measured and returned to Flask.
7. The frontend displays the result matrix, execution time, speedup, efficiency, and performance chart.

## 🧮 Mathematical Representation

Matrix multiplication is performed using the following formula:

\[
C_{ij} = \sum_{k=0}^{n-1} A_{ik} \times B_{kj}
\]

Where:

- A and B are the input matrices.
- C is the resultant matrix.
- n is the matrix dimension.
- i, j, and k represent matrix indices.

## ⚡ Parallelization Using OpenMP

The project uses the OpenMP parallel-for directive to distribute matrix rows among multiple threads.

```c
#pragma omp parallel for num_threads(threads) schedule(static)
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        double sum = 0.0;

        for (int k = 0; k < n; k++) {
            sum += A[i][k] * B[k][j];
        }

        C[i][j] = sum;
    }
}
```

Each thread processes a portion of the matrix rows, allowing multiple calculations to execute concurrently.

## 📊 Performance Metrics

The application calculates the following metrics:

**1. Execution Time**

Time taken to complete matrix multiplication.

**2. Speedup**

\[
Speedup = \frac{Sequential\ Time}{Parallel\ Time}
\]

**3. Parallel Efficiency**

\[
Efficiency = \frac{Speedup}{Number\ of\ Threads} \times 100
\]

These metrics help evaluate the performance of parallel matrix multiplication.
